## REF-07 — Severe-distortion continuum benchmark

**Test:** `test_q4_severe_distortion_solver.f90`

Mesh center:

```text
X5 = (1.45, 0.55)
```

Reference Gauss weight/Jacobian:

```text
min ≈ 0.07255
max ≈ 0.42745
ratio ≈ 0.1697
```

Exact affine deformation:

```text
F = [1.35  0.28  0]
    [0.12  0.78  0]
    [0     0     1]

J = 1.0194
```

Material:

```text
mu = 2.7
lambda = 25.0
```

Test içindeki bağımsız referans FEM/material-response API çağırmaz:

```text
W = mu/2 (I1-3) - mu ln(J) + lambda/2 [ln(J)]²
P = mu F + [lambda ln(J)-mu] F^{-T}
```

Approximate reference:

```text
P11 =  1.94662573
P12 =  1.01728835
P21 =  0.93367281
P22 = -0.83349393
P33 =  0.48035547
W   =  0.6597314365
```

Kontroller:
- center displacement
- global force balance
- 16 Gauss `F/J`
- weighted `P`
- total reference area
- total strain energy
- min `J`
- Newton/linear diagnostics.

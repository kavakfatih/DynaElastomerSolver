**Sürüm:** V0.2-dev  
**Kapsam:** Plane-strain, finite-strain, sıkıştırılabilir Neo-Hookean, Q4, quasi-static Full Newton

## REF-01 — Neo-Hookean material-point tangent

**Test:** `test_neo_hookean_material_point.f90`  
**Referans:** merkezi finite-difference ile `dP/dF`  
**Amaç:** analitik consistent material tangent'in constitutive response ile uyumunu doğrulamak.

Başlıca kanıt:
- normalize tangent hatası yaklaşık `1.26e-9` seviyesinde elde edilmiştir.

Kabul:
- analitik tangent ve merkezi FD sonucu test toleransı içinde eşleşir.
- `J <= 0`, singular `F` ve geçersiz parametreler kontrollü failure üretir.

## REF-02 — Q4 element tangent

**Test:** `test_q4_plane_strain_element.f90`  
**Referans:** element residual'ının merkezi finite-difference türevi  
**Amaç:** `K = dR/du` tutarlılığını element seviyesinde doğrulamak.

Başlıca kanıt:
- normalize element tangent FD hatası yaklaşık `1.16e-9`.

Bu test önemlidir; çünkü material tangent doğru olsa bile shape-gradient, mapping veya assembly türevi hatalı olabilir.

## REF-03 — Homojen plane-strain extension

**Testler:**
- `test_q4_plane_strain_newton.f90`
- `test_q4_solver_api.f90`
- `test_q4_plane_strain_mesh_newton.f90`

**Referans türü:** kapalı-form/homojen continuum çözümü.

Tanımlı örnek:
- `lambda_x = 1.25`
- lateral yüzeyde traction-free koşulundan `lambda_y` bağımsız scalar çözümle hesaplanır
- FE reaksiyonu constant First Piola-Kirchhoff stress referansı ile karşılaştırılır.

Önceden doğrulanan örnek sonuç:
- `lambda_y ≈ 0.831469`
- iki elemanlı reaksiyon relative error yaklaşık `1e-15`
- final free residual yaklaşık `5.4e-15`.

Kabul:
- displacement, lateral contraction ve reaksiyon tanımlı tolerans içinde continuum referansıyla eşleşir.

## REF-04 — Nonlinear patch ve mesh refinement

**Testler:**
- `test_q4_nonlinear_patch.f90`
- `test_q4_mesh_refinement.f90`

**Amaç:** mapping + element + global assembly + Newton zincirinin mesh değişiminde tutarlılığını doğrulamak.

Patch:
- distorsiyonlu 2×2 Q4 mesh
- affine finite-strain displacement alanı
- merkez serbest düğümün affine çözümü yeniden üretmesi beklenir.

Önceden doğrulanan merkez hata seviyesi:
- yaklaşık `3.9e-17`.

Mesh refinement:
- 1×1 / 2×2 / 4×4 homojen mesh
- reaksiyon sonucu `1.605586` olarak korunmuştur.

Kabul:
- affine patch exactness
- global kuvvet dengesi
- homojen problemde mesh-independent reaction.

## REF-05 — Adaptive rollback / cutback / retry

**Testler:**
- `test_q4_adaptive_cutback.f90`
- `test_solver_state_history.f90`

**Amaç:** nonlinear çözüm başarısızlığında state'in fiziksel ve deterministik biçimde yönetildiğini doğrulamak.

Senaryo:

```text
%100 ilk increment
    ↓
J <= 0
    ↓
trial reddedilir
    ↓
revert
    ↓
%50 cutback
    ↓
retry + commit
```

Kabul:
- başarısız trial committed state'i bozmaz
- failure nedeni history içinde korunur
- cutback sonrası güvenli çözüm referans fixed-step çözümüyle eşleşir
- cutback sınırı tükenirse kontrollü `DES_ERROR_CUTBACK_EXHAUSTED` oluşur.

## REF-06 — InternalMesh ve ham integration-point sonuçları

**Testler:**
- `test_internal_mesh_integration_results.f90`
- `test_q4_internal_mesh_solver.f90`

**Amaç:** kanonik mesh modeline geçişin fizik sonucunu değiştirmediğini ve ham Gauss verisinin kayıpsız üretildiğini doğrulamak.

Kontroller:
- eski `X + connectivity` ve yeni `InternalMesh` assembly residual/tangent eşdeğerliği
- Q4 başına dört integration point
- `F / J / P / Cauchy / strain-energy` saklama
- invalid/duplicate-node connectivity rejection.

Affine referans örneği:
- `F = diag(1.10, 0.95, 1.0)`
- tüm Gauss noktalarında `J = 1.045`.

## REF-07 — Severe-distortion continuum benchmark

**Test:** `test_q4_severe_distortion_solver.f90`

Bu V0.2'nin en güçlü geometri/assembly benchmarklarından biridir.

### Referans mesh

2×2 Q4 dikdörtgen mesh, merkez düğüm:

```text
X5 = (1.45, 0.55)
```

Reference Gauss ağırlığı/Jacobian aralığı yaklaşık:

```text
min ≈ 0.07255
max ≈ 0.42745
min/max ≈ 0.1697
```

### Uygulanan exact affine deformation

```text
F = [ 1.35   0.28   0 ]
    [ 0.12   0.78   0 ]
    [ 0      0      1 ]

J = 1.0194
```

Malzeme:
- `mu = 2.7`
- `lambda = 25.0`

### Bağımsız kapalı-form continuum referansı

Test içindeki referans rutin FEM assembly, `des_neo_hookean` veya material-response API'sini çağırmaz.

Ayrı olarak hesaplar:

```text
W = mu/2 (I1 - 3) - mu ln(J) + lambda/2 [ln(J)]²
P = mu F + [lambda ln(J) - mu] F^{-T}
```

Bu kapalı-form referans ile aşağıdakiler karşılaştırılır:

1. Her Gauss noktasındaki `F`
2. Her Gauss noktasındaki `J`
3. Tüm Gauss noktalarının reference-weighted ortalama `P` tensörü
4. Toplam referans alanı
5. Entegre toplam strain energy
6. Serbest merkez düğüm displacement'i
7. Global kuvvet dengesi
8. Newton ve lineer solver diagnostics.

Bağımsız ön hesapta kapalı-form değerler yaklaşık:

```text
J = 1.0194

P ≈
[ 1.94662573   1.01728835   0 ]
[ 0.93367281  -0.83349393   0 ]
[ 0             0           0.48035547 ]

W ≈ 0.6597314365
```

Referans alan `4.0` olduğundan exact toplam strain energy yaklaşık:

```text
E = 4 W ≈ 2.6389257461
```

Kabul:
- center displacement error ≤ `5e-10`
- Gauss `F` max error ≤ `5e-10`
- Gauss `J` error ≤ `5e-10`
- weighted `P` max error ≤ `5e-10`
- total energy error ≤ `5e-10`
- global force sums ≤ `5e-9`
- lineer residual max ≤ `1e-9`
- tüm material `J > 0`.

Bu problem daha sonra bağımsız dış FEM solver karşılaştırmasında da kullanılacak ana adaydır.

## V0.2 için dış solver karşılaştırması

Kapalı-form referanslar element/solver hatalarını güçlü biçimde yakalar; ancak ürün güvenilirliği için tek başına yeterli kabul edilmeyecektir.

V0.2 kapanışında en az bir tanımlı problem bağımsız bir FEM implementasyonuyla yeniden çözülecek ve aşağıdaki çıktılar karşılaştırılacaktır:

- displacement
- reaction/resultant
- `J`
- stress ölçüsü ve kullanılan stress tanımının açık dönüşümü
- strain energy
- mesh/refinement davranışı.

İlk dış-solver adayı REF-03 homojen extension veya REF-07 severe-distortion affine benchmarkıdır.

Karşılaştırmada solver varsayımları, element tipi, integration order, material enerji fonksiyonu ve plane-strain koşulu dosyada açıkça kaydedilecektir.

## Ortak material law

Displacement baseline'ın Neo-Hookean enerjisi:

```text
Psi(F) = mu/2 (I1 - 3)
       - mu ln(J)
       + lambda/2 [ln(J)]^2
```

Mixed formulation aynı fiziği bağımsız pressure ile yeniden yazar:

```text
Psi(F,p) = mu/2 (I1 - 3)
         - mu ln(J)
         + p ln(J)
         - p^2/(2 lambda)
```

Stationarity:

```text
ln(J) - p/lambda = 0
p = lambda ln(J)
```

Bu ilişki geri yerleştirildiğinde baseline enerji birebir elde edilir. Bu nedenle mixed karşılaştırmada material law değil volumetrik alanın ayrıklaştırılması değişir.

## Aday B — Mixed Q4/P0

Element unknownları:

```text
8 displacement DOF + 1 constant element pressure DOF
```

Global unknown sırası:

```text
[u1x,u1y,...,unx,uny | p1,p2,...,p_nelem]
```

Gerilme ve residual:

```text
P = mu F + (p-mu) F^{-T}
Ru = integral(P_iJ N_a,J dV0)
Rp = integral[ln(J)-p/lambda] dV0
```

Block Newton sistemi:

```text
[ Kuu  Kup ] [du] = -[Ru]
[ Kpu  Kpp ] [dp]    [Rp]
```

Tamamlanan zincir:

- 9x9 element residual/tangent
- merkezi FD tangent doğrulaması
- yerel GNU Fortran 14.2 tangent error ≈ `1.74e-9`
- global mixed assembly
- mixed Full Newton force-control
- homogeneous analytic traction benchmark
- Cook 2x2 / 4x4 / 8x8 benchmark

### Pressure diagnostics

P0 pressure alanı artık yalnız min/max ile değerlendirilmez. `des_pressure_diagnostics` aşağıdaki metrikleri üretir:

- min / max / mean
- standard deviation
- RMS
- edge-neighbor pair count
- neighbor pressure-jump RMS
- maximum neighbor jump
- normalized neighbor-jump RMS
- mean-free `neighbor_jump_to_std`
- `graph_roughness = (neighbor_jump_rms/pressure_std)^2`

İki eleman tam bir Q4 kenarı yani iki ortak node paylaşıyorsa neighbor kabul edilir.

**Önemli:** pressure jump/roughness tek başına checkerboard veya instability kararı değildir; gerçek pressure gradient de jump üretir. Mesh-refinement trendi ve bağımsız solver pressure alanı ile birlikte yorumlanacaktır.

### Manufactured homojen pressure-uniformity referansı

Pressure diagnostics için exact bir sıfır-roughness referansı eklendi:

`tests/test_v03_mixed_pressure_uniformity.f90`

Düzenli 2x2 Q4 mesh üzerinde homojen affine deformasyon uygulanır:

```text
F2 = [1.10  0.08]
     [0.03  0.94]

J = 1.0316
p = lambda ln(J)
mu = 2.3
lambda = 19
```

Q4 bu affine alanı exact temsil eder ve her P0 elementine aynı exact pressure atanır. Bu durumda:

```text
R_p = integral[ln(J)-p/lambda] dV0 = 0
```

olmalıdır.

Yerel GNU Fortran 14.2 doğrulaması:

```text
Exact J                    = 1.031600
Exact pressure             = 0.5911089
maximum pressure residual  = 1.11e-16
pressure graph roughness   = 0.0
```

Ayrıca pressure standard deviation, bütün neighbor jump ölçüleri ve normalize roughness değerleri sıfırdır. Bu test Cook problemindeki gerçek pressure gradientini doğrulamaz; yalnız mixed pressure stationarity + diagnostics zincirinin homojen alanda yapay dalgalanma üretmediğini exact referansla kanıtlar.

Q4/P0 hâlâ production formulation seçimi değildir.

## Aday C — F-bar Q4

Her Gauss noktasındaki gerçek plane-strain deformation gradient için:

```text
J_bar = integral(J dV0) / integral(dV0)
alpha_g = (J_bar/J_g)^(1/3)
F_bar_g = alpha_g F_g
```

Dolayısıyla:

```text
det(F_bar_g) = J_bar
```

Dyna 3x3 deformation-gradient temsili kullandığı için volumetric scaling üç boyutlu determinant üzerinden yapılır.

### Energy-consistent residual

Element yalnız düzeltilmiş `F_bar` ile standart residual çağırmaz. Element enerjisi:

```text
E(u) = sum_g W(F_bar_g(u)) w_g
```

olarak alınır ve residual bu enerjinin ilk varyasyonundan hesaplanır. Böylece `J_bar` nedeniyle Gauss noktaları arasında oluşan coupling residualda yer alır.

### Analitik consistent tangent

İlk verification prototipindeki merkezi finite-difference tangent kaldırılmıştır. Tangent artık aynı enerjinin ikinci varyasyonundan analitik hesaplanır.

Bir nodal DOF `q` için:

```text
H_q = dF_bar/dq
    = alpha [ B_q + beta_q F ]

beta_q = 1/3 [ J_bar,q/J_bar - J,q/J ]
```

Element tangent:

```text
K_qr = sum_g w_g [ H_q : A_bar : H_r + P_bar : H_qr ]
```

şeklindedir. `H_qr`; `alpha`, `J` ve `J_bar`ın ikinci türevlerini içerdiği için Gauss noktaları arasındaki F-bar volumetrik coupling ikinci varyasyonda da korunur.

Bağımsız sayısal türev kontrolleri:

```text
Python derivation/reference:
normalized Frobenius cross-FD error ≈ 8.73e-10
symmetry error                      ≈ 1.90e-16

GNU Fortran 14.2 local element check:
max normalized cross-FD error       ≈ 1.20e-9
symmetry error                      ≈ 2.45e-16
```

Bu sonuçlar lokal bilimsel doğrulamadır; Windows/macOS compiler matrix yeniden çalışmadan platform doğrulaması tamamlanmış sayılmaz.

Tamamlanan zincir:

- `des_q4_plane_strain_fbar_neo_hookean.f90`
- energy-consistent F-bar residual
- analitik consistent tangent
- homogeneous residual-equivalence testi
- independent cross-FD tangent testi
- global F-bar assembly
- F-bar force-control Full Newton
- homogeneous analytic traction benchmark
- F-bar Cook 2x2 / 4x4 / 8x8 benchmark

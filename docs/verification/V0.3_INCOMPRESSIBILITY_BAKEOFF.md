## Ortak material law

Displacement baseline'ın Neo-Hookean enerjisi:

```text
Psi(F) = mu/2 (I1 - 3)
       - mu ln(J)
       + lambda/2 [ln(J)]^2
```

Mixed formulation aynı fiziği bağımsız pressure ile yeniden yazar:

```text
Psi(F,p) = mu/2 (I1 - 3)
         - mu ln(J)
         + p ln(J)
         - p^2/(2 lambda)
```

Stationarity:

```text
ln(J) - p/lambda = 0
p = lambda ln(J)
```

Bu ilişki geri yerleştirildiğinde baseline enerji birebir elde edilir. Bu nedenle mixed karşılaştırmada material law değil volumetrik alanın ayrıklaştırılması değişir.

## Aday B — Mixed Q4/P0

Element unknownları:

```text
8 displacement DOF + 1 constant element pressure DOF
```

Global unknown sırası:

```text
[u1x,u1y,...,unx,uny | p1,p2,...,p_nelem]
```

Gerilme ve residual:

```text
P = mu F + (p-mu) F^{-T}
Ru = integral(P_iJ N_a,J dV0)
Rp = integral[ln(J)-p/lambda] dV0
```

Block Newton sistemi:

```text
[ Kuu  Kup ] [du] = -[Ru]
[ Kpu  Kpp ] [dp]    [Rp]
```

Tamamlanan zincir:

- 9x9 element residual/tangent
- merkezi FD tangent doğrulaması
- yerel GNU Fortran 14.2 tangent error ≈ `1.74e-9`
- global mixed assembly
- mixed Full Newton force-control
- homogeneous analytic traction benchmark
- Cook 2x2 / 4x4 / 8x8 benchmark

### Pressure diagnostics

P0 pressure alanı artık yalnız min/max ile değerlendirilmez. `des_pressure_diagnostics` aşağıdaki ham metrikleri üretir:

- min / max / mean
- standard deviation
- RMS
- edge-neighbor pair count
- neighbor pressure-jump RMS
- maximum neighbor jump
- normalized neighbor-jump RMS

İki eleman tam bir Q4 kenarı yani iki ortak node paylaşıyorsa neighbor kabul edilir.

**Önemli:** neighbor jump tek başına checkerboard/instability kararı değildir; gerçek pressure gradient de jump üretir. Mesh-refinement trendi ve bağımsız solver pressure alanı ile birlikte yorumlanacaktır.

Q4/P0 hâlâ yalnız ilk mixed prototiptir.

## Aday C — F-bar Q4 verification prototype

İlk F-bar prototipi uygulanmıştır.

Her Gauss noktasındaki gerçek plane-strain deformation gradient için:

```text
J_bar = integral(J dV0) / integral(dV0)
alpha_g = (J_bar/J_g)^(1/3)
F_bar_g = alpha_g F_g
```

Dolayısıyla:

```text
det(F_bar_g) = J_bar
```

Dyna 3x3 deformation-gradient temsili kullandığı için volumetric scaling üç boyutlu determinant üzerinden yapılır.

### Energy-consistent residual

Prototip yalnız düzeltilmiş `F_bar` ile standart residual çağırmaz. Element enerjisi:

```text
E(u) = sum_g W(F_bar_g(u)) w_g
```

olarak alınır ve residual bu enerjinin ilk varyasyonundan hesaplanır. Böylece `J_bar` nedeniyle Gauss noktaları arasında oluşan coupling residualda yer alır.

### Tangent durumu

İlk prototipte tangent, energy-consistent residualın merkezi finite-difference türevidir.

Bu bilinçli verification-first kararıdır:

- formulation davranışını hızlı ve bağımsız doğrulamak
- Cook benchmarkında mixed/displacement ile karşılaştırmak
- yalnız F-bar production adayı olarak ayakta kalırsa analitik consistent tangent türetmek

Tamamlanan/eklenen zincir:

- `des_q4_plane_strain_fbar_neo_hookean.f90`
- F-bar element residual
- numerical verification tangent
- homogeneous residual-equivalence testi
- independent cross-FD tangent testi
- global F-bar assembly
- F-bar force-control Full Newton
- homogeneous analytic traction benchmark
- F-bar Cook 2x2 / 4x4 / 8x8 benchmark

### Açık kaynak algoritmik referans

MOOSE'un güncel finite-strain ve plane finite-strain uygulamalarında volumetric-locking correction element-average determinant kullanır ve deformation gradient'i cube-root determinant oranıyla ölçekler. Dyna bu kaynağı algoritmik referans olarak kullanır; residual/tangent implementasyonu kendi kodumuzdur.

Referanslar:
- https://mooseframework.inl.gov/docs/doxygen/modules/classComputeFiniteStrain.html
- https://mooseframework.inl.gov/docs/doxygen/modules/classComputePlaneFiniteStrain.html

## Ortak Cook-benzeri benchmark

Normalize geometri:

```text
sol alt = (0, 0)
sağ alt = (1, 44/48)
sağ üst = (1, 60/48)
sol üst = (0, 44/48)
```

Boundary conditions:

- sol kenar tam ankastre
- sağ kenarda yukarı reference nominal traction

Material baseline:

```text
mu = 1
lambda = 1000
```

Meshler:

```text
2x2
4x4
8x8
```

İleride daha ince mesh ve bağımsız dış FEM reference eklenecektir.

## Neden benchmark gerekli?

Tam integrasyonlu düşük dereceli Quad4 elemanlar malzeme incompressible sınıra yaklaştığında volumetric locking nedeniyle yapay biçimde aşırı rijit davranabilir. MOOSE resmi Solid Mechanics dokümantasyonu bunu Quad4 için açıkça tanımlar ve Cook membrane problemini locking doğrulaması olarak kullanır.

Referans:
- https://mooseframework.inl.gov/modules/solid_mechanics/VolumetricLocking.html

MFEM'in resmi incompressible nonlinear elasticity örneği pressure'ı bağımsız unknown olarak kullanır ve Newton adımında displacement-pressure saddle-point block sistemi çözer.

Referanslar:
- https://mfem.org/examples/
- https://docs.mfem.org/4.7/classmfem_1_1IncompressibleNeoHookeanIntegrator.html
- https://github.com/mfem/mfem

Bu dış kaynaklar algoritmik/fizik referansıdır; Dyna formulation kodu kendi implementasyonumuzdur.

## Aday A — Displacement-only Q4

Bu, V0.2'den gelen doğrulanmış baseline'dır.

Global unknown:

```text
q = [u]
```

Mevcut compressible Neo-Hookean enerji:

```text
Psi(F) = mu/2 (I1 - 3)
       - mu ln(J)
       + lambda/2 [ln(J)]^2
```

Bu formulation V0.3'te referans olarak korunur; near-incompressible `lambda/mu` oranı büyütüldüğünde locking davranışı ölçülür.

## Aday B — İlk mixed Q4/P0 prototipi

İlk mixed prototip bilinçli olarak minimum tutulmuştur:

- displacement: Q4, 8 element DOF
- pressure: element başına sabit P0, 1 element DOF

Global unknown sırası:

```text
q = [u1x,u1y,...,unx,uny | p1,p2,...,p_nelem]
```

### Ortak malzeme fiziğini koruyan mixed potansiyel

Displacement-only model ile farklı bir malzeme kanunu karşılaştırmamak için mevcut Neo-Hookean enerji bağımsız pressure değişkeniyle yeniden yazılmıştır:

```text
Psi(F,p) = mu/2 (I1 - 3)
         - mu ln(J)
         + p ln(J)
         - p^2/(2 lambda)
```

Pressure stationarity:

```text
dPsi/dp = ln(J) - p/lambda = 0
```

Dolayısıyla noktasal pressure serbestliği için:

```text
p = lambda ln(J)
```

ve bu değer enerjiye geri yerleştirildiğinde displacement-only V0.2 enerjisi birebir geri elde edilir:

```text
Psi(F) = mu/2 (I1 - 3)
       - mu ln(J)
       + lambda/2 [ln(J)]^2
```

Bu nedenle ilk karşılaştırmada malzeme modeli değil, **volumetrik alanın ayrıklaştırılması** değişmektedir.

### Mixed gerilme ve residual

```text
P = mu F + (p - mu) F^{-T}

R_u = integral(P_iJ N_a,J dV0)
R_p = integral[ln(J) - p/lambda] dV0
```

Block tangent:

```text
[ K_uu  K_up ]
[ K_pu  K_pp ]
```

ile doğrudan Newton sistemine girer.

### İlk doğrulama

`test_q4_mixed_up_element.f90`:

- 8 displacement + 1 pressure = 9 unknown
- tam 9x9 tangent merkezi finite-difference ile kontrol edilir
- yerel GNU Fortran 14.2 kontrolünde normalize tangent hatası yaklaşık `1.74e-9`
- homojen durumda `p=lambda ln(J)` seçildiğinde mixed displacement residualının mevcut Neo-Hookean Q4 residualını geri üretmesi beklenir

### Önemli sınırlama

Q4/P0 bu aşamada **production seçimi değildir**. Pressure interpolation'ın stability / checkerboard davranışı mesh benchmarklarında ölçülecektir. Sonuç kötü çıkarsa formulation reddedilecek veya daha uygun pressure space/stabilization adayı değerlendirilecektir.

## Ortak benchmark — Cook-benzeri membrane

Dyna ilk baseline geometrisini normalize eder:

```text
sol alt   = (0, 0)
sağ alt   = (1, 44/48)
sağ üst   = (1, 60/48)
sol üst   = (0, 44/48)
```

Boundary conditions:

- sol kenar tam ankastre
- sağ kenarda yukarı reference nominal traction

İlk material seviyesi:

```text
mu = 1
lambda = 1000
```

Meshler:

```text
2x2
4x4
8x8
```

İleride en az bir daha ince mesh reference olarak eklenecektir.

## Ölçülecek ortak metrikler

Her formulation için aynı tabloda:

- sağ kenar midpoint/tip displacement
- mesh refinement trendi
- coarse-to-fine locking göstergesi
- pressure min/max/mean
- pressure oscillation/checkerboard göstergesi
- minimum material `J`
- Newton iteration sayısı
- failed increment sayısı
- lineer solve sayısı
- lineer residual
- global DOF sayısı
- matrix boyutu
- çözüm süresi daha sonra
- distortion sensitivity

Production kararında yalnız tek displacement sayısı kullanılmayacaktır.

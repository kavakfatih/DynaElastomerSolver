# V0.3 — Commercial Mixed u-P Parity Kabul Planı

**Durum:** Aktif doğrulama planı  
**Tarih:** 2026-08-19  
**Ana Dyna adayı:** Q9/P1 Herrmann / stable mixed `u-p`  
**Referans ürünler:** ANSYS current-technology mixed `u-P`; Hexagon Marc nonlinear/Herrmann davranışı

## 1. Amaç

Bu planın amacı DynaElastomerSolver için "ticari solver seviyesinde" ifadesini pazarlama cümlesi değil, ölçülebilir kabul zinciri haline getirmektir.

Dyna'nın bir benchmarkta tek displacement değerini eşleştirmesi yeterli değildir. Commercial parity ancak aynı problem sözleşmesinde şu sınıflar birlikte doğrulandığında kabul edilir:

```text
kinematics
+ mixed pressure field
+ incompressibility
+ consistent tangent
+ mesh convergence
+ distortion robustness
+ nonlinear robustness
+ pressure uniqueness/precheck
+ result semantics
+ solver scalability
```

Bu belge parity'yi ilan etmez; parity iddiası için kapıları tanımlar.

---

## 2. ANSYS davranış referansı

Güncel ANSYS element/theory dokümantasyonundan alınan davranış hedefleri:

- current-technology mixed `u-P` formulation displacement ve hydrostatic pressure'ı bağımsız primary unknown olarak çözer,
- pressure unknown'ları element seviyesinde elimine edilmek yerine global çözüm sisteminde tutulabilir,
- formulation fully ve nearly incompressible hyperelasticity için kullanılır,
- PLANE183 quadratic displacement davranışlı yüksek mertebeli 2D elementtir,
- PLANE183 plane strain, axisymmetric ve axisymmetric-with-torsion problem sınıflarını destekler,
- PLANE183 mixed formulation seçeneğinde sparse solver kullanımı zorunludur,
- mixed model için `Nd/Np` overconstraint kontrolü önemlidir; 2D için hedef oran yaklaşık 2 olarak verilir,
- fully incompressible durumda tüm displacement sınırları basıncı belirsiz bırakacak biçimde kısıtlanırsa pressure uniqueness problemi oluşabilir,
- volume constraint nonlinear analiz sırasında ayrıca izlenir; weak compatibility ile pointwise strain/stress eşitliği aynı kavram değildir.

Dyna bu davranışları kaynak kod kopyalamadan bağımsız formulation ve test sözleşmeleriyle karşılar.

---

## 3. Marc davranış referansı

Hexagon Marc; hyperelasticity, large deformation, contact ve güçlü nonlinear çözüm kabiliyetleri olan genel nonlinear FEA solverıdır. Marc'ın Herrmann formulation ailesi incompressibility için tarihsel/teknik davranış referansıdır.

Dyna için Marc parity değerlendirmesinde yalnız element ismi eşleştirilmez. Aşağıdaki sonuç davranışları karşılaştırılır:

- nearly/fully incompressible displacement response,
- hydrostatic pressure quality,
- mesh refinement,
- distorted element robustness,
- load-step/cutback davranışı,
- reaction force/torque,
- axisymmetric ve ileride axisymmetric-with-torsion çözümü.

Marc'ın proprietary implementasyon ayrıntıları Dyna'ya taşınmaz.

## 4. Zorunlu benchmark matrisi

### C1 — Plane-strain manufactured affine state

Amaç:

- exact displacement recovery,
- exact pressure mode recovery,
- `J` ve pressure sign convention,
- residual/tangent doğruluğu.

Pressure alanları:

```text
constant
xi
eta
constant + xi + eta
```

Kabul:

```text
max displacement error <= 1e-7
max pressure error     <= 1e-7
pressure weak residual <= 1e-9
```

### C2 — Analytic consistent tangent

Her supported quadrature ve compressibility rejiminde central finite-difference cross-check.

Kabul:

```text
release gate <= 1e-7
nominal goal <= 1e-8
```

Tolerans yalnız compiler noise gerekçesiyle belgeli biçimde değiştirilebilir; formulation hatasını gizlemek için gevşetilemez.

### C3 — Pressure stability

- coupling rank,
- checkerboard/alternating mode,
- inf-sup proxy mesh trendi,
- distorted mesh pressure stability,
- `Nd/Np` precheck.

Q9/P1 mevcut regression alt sınırları korunur.

### C4 — Cook nearly-incompressible mesh convergence

Ortak problem sözleşmesi:

```text
mu = 1
pressure compliance = 1e-3
traction_y = 0.01
right-edge geometric midpoint result
```

Dyna mesh zinciri en az:

```text
1x1 -> 2x2 -> 4x4 Q9/P1
```

Bağımsız reference:

```text
FEniCSx Q2 + discontinuous complete-linear pressure
2x2 -> 4x4 -> 8x8 -> 16x16
```

Commercial deck geldiğinde ANSYS/Marc aynı geometri/yük/material convention ile eklenir.

### C5 — Quadrature convergence

Dyna:

```text
2x2 -> 3x3 -> 4x4
```

FEniCSx:

```text
Basix 4-point -> 9-point -> 16-point -> 25-point cell quadrature
```

Amaç underintegration kaynaklı farkı formulation farkından ayırmaktır.

Primary quadrature ancak higher-order integration ve external reference ile stabilize olduğu gösterilerek seçilir.

### C6 — Fully incompressible saddle-point

```text
pressure compliance = 0
K_pp = 0
J=1 weak constraint
pressure = independent Lagrange multiplier
```

Kabul:

- nonlinear convergence,
- pressure solution uniqueness uygun BC altında,
- finite displacement/pressure,
- `J > 0`,
- weak pressure residual gate,
- independent external mixed solution.

### C7 — Severe distortion

Distorted Q9 geometry exact/manufactured state ve loaded Cook türü problemle test edilir.

Kabul:

```text
positive reference Jacobian
positive deformation J
state recovery <= 1e-7 (manufactured case)
no spurious pressure mode
stable Newton convergence
```

### C8 — Nonlinear robustness

En az:

- full Newton,
- adaptive load increment,
- cutback/retry,
- displacement + pressure rollback,
- deterministic convergence/failure reason,
- minimum `J`,
- separate `R_u` and `R_p`,
- volumetric compatibility diagnostic.

Commercial comparison yalnız converged final sayı üzerinden değil iteration/cutback davranışı üzerinden de raporlanır.

### C9 — Result semantics

Ayrı raporlar:

- independent pressure unknown,
- pressure sign/measure,
- actual kinematic `F/J`,
- pointwise volumetric compatibility diagnostic,
- weak pressure residual,
- stress/reaction.

Farklı solver pressure conventionları önce normalize edilir; aksi halde pressure error yüzdesi hesaplanmaz.

### C10 — Linear algebra / model size

Dense LAPACK verification baseline olarak kalabilir; commercial-scale parity için production yol:

```text
block sparse assembly
+ sparse direct baseline
+ conditioning/scaling diagnostics
+ Schur/field-split option
```

ANSYS PLANE183 mixed formulationın sparse solver gerektirmesi Dyna için de ölçeklenebilir sparse mixed solve gereksinimini güçlendirir.

## 5. Sayısal parity eşikleri

Aynı discrete space ve aynı quadrature ile bağımsız FEniCSx karşılaştırmasında hedef:

```text
midpoint displacement relative error <= 2e-5
pressure mean/std/RMS relative error  <= 2e-4
constraint L2-RMS relative error      <= 5e-4
average J absolute error              <= 5e-7
```

Farklı mesh/element teknolojisi ile continuum-reference karşılaştırmasında release hedefi:

```text
displacement relative error <= 1.0%
pressure L2-type error       <= 2.0%  [aynı pressure measure/sign]
```

ANSYS/Marc commercial deck için başlangıç hedefi aynı continuum seviyesidir. Sonuçlar bundan daha iyi ise ölçülen değer kaydedilir; threshold sonuca uydurulmaz.

## 9. Parity sınıflandırması

```text
LEVEL 0 — Implemented
  Kod çalışıyor; parity iddiası yok.

LEVEL 1 — Internal Verified
  analytic/FD, patch, stability, mesh/distortion, nonlinear gates geçti.

LEVEL 2 — Independent Verified
  bağımsız FEniCSx mixed reference kapıları geçti.

LEVEL 3 — Commercial Benchmarked
  aynı benchmark contractında ANSYS ve/veya Marc sonucu ile karşılaştırıldı.

LEVEL 4 — Product Validated
  ticari solver karşılaştırmasına ek olarak fiziksel test doğrulandı.
```

V0.3 plane-strain hedefi minimum **LEVEL 2**'dir. ANSYS/Marc deck erişimi sağlandığında **LEVEL 3** kapatılır. Axisymmetric-with-torsion production hedefi **LEVEL 4** olmadan tamamlandı sayılmaz.

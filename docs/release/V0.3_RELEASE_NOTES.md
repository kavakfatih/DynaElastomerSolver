# DynaElastomerSolver V0.3.0 — Release Notes

**Durum:** Release adayı / final entegrasyon kontrolü  
**Ana tema:** Nearly-incompressible plane-strain production baseline  
**Production formulation:** F-bar Q4  
**Karar kaydı:** ADR-0007

> Bu belge V0.3.0 için release notu taslağıdır. PR #1 final release kontrolü tamamlanmadan `main`e merge edilmez ve `v0.3.0` tag yayınlanmaz.

---

## Özet

V0.3.0, DynaElastomerSolver'ın yaklaşık sıkıştırılamaz elastomer problemleri için plane-strain production formulationını bilimsel benchmarklarla seçtiği sürümdür.

Üç formulation aynı problem sözleşmesi altında karşılaştırıldı:

- displacement-only Q4
- mixed Q4/P0 `u-p`
- F-bar Q4

Sonuç:

```text
F-bar Q4        = production default
Displacement Q4 = baseline / regression
Mixed Q4/P0     = experimental / verification
```

Bu seçim yalnız tek bir Cook displacement değerine dayanmaz; locking, dış Q2 referans, pressure-space stability, consistent tangent, severe distortion, platform reproducibility, equation count, nonlinear solve davranışı ve Results semantiği birlikte değerlendirilmiştir.

## Başlıca yenilikler

### F-bar Q4 production formulation

F-bar volumetric correction:

```text
J_bar = integral(J dV0) / integral(dV0)
alpha = (J_bar/J)^(1/3)
F_bar = alpha F
```

Residual aynı element enerjisinin ilk varyasyonundan, tangent analitik ikinci varyasyonundan hesaplanır.

Doğrulama:

```text
Python cross-FD  ≈ 8.73e-10
Python symmetry  ≈ 1.90e-16
GNU Fortran FD   ≈ 1.20e-9
GNU symmetry     ≈ 2.45e-16
```

### Birleşik Cook formulation bake-off

Resmi dış referans:

```text
FEniCSx/DOLFINx Q2 32x32 tip = 0.0201973648361
16x16 -> 32x32 change        = 0.846316%
```

### Results pressure contract

V0.3 artık gerçek kinematik state ile constitutive state'i açıkça ayırır:

```text
F, J                           = gerçek Gauss kinematiği
constitutive_F, constitutive_J = malzeme modelinin kullandığı state
```

Pressure scalar:

```text
p_logJ = lambda * ln(constitutive_J)
```

Bu scalar `-tr(sigma)/3` hidrostatik Cauchy basıncı değildir.

Kaynak ayrımı:

```text
DES_PRESSURE_SOURCE_DERIVED_CONSTITUTIVE
DES_PRESSURE_SOURCE_INDEPENDENT_UNKNOWN
```

F-bar için:

```text
constitutive_F = F_bar
constitutive_J = J_bar
source         = DERIVED_CONSTITUTIVE
```

Non-affine contract testi:

```text
local J range          = 4.272392e-02
J vs constitutive J    = 2.136196e-02
J_bar                  = 1.149200
Derived p_logJ         = 2.642255
```
